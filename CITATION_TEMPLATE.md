# Citation metadata template — not a published citation

After author approval, create a root `CITATION.cff` containing **actual** authors, version, title, year, repository URL and DOI (when assigned). Example syntax to edit, not publish unchanged:

```yaml
cff-version: 1.2.0
message: "Please cite the version of this research software used in your work."
title: "Human–AI conflict in intelligent processing systems: simulation and verification archive"
type: software
authors:
  - family-names: "[REAL FAMILY NAME]"
    given-names: "[REAL GIVEN NAME]"
version: "1.0.0"
date-released: "[YYYY-MM-DD]"
repository-code: "https://github.com/Rajeevan-A/human-ai-conflict-CSTR-reproducibility"
# doi: "10.xxxx/real.deposit.id"  # only once issued
```

Add `preferred-citation` after journal publication with authentic article details. Cite the exact GitHub tag and software DOI rather than just the mutable `main` branch. The existing uploaded archives and third-party ASTE material must be attributed separately according to their permitted licensing conditions.
